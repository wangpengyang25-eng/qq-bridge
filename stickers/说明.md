# 表情包（按「情绪名」发送）

当前只有一套：**`04-线条狗`**（43 张动态 GIF）。

```
stickers/
├── 04-线条狗/          43 个情绪，共 43 张
├── 预览.html           ★ 看全套图 + 情绪名，挑情绪用
└── 说明.md
```

浏览器打开 **`预览.html`** 就能一次看全，每张图下面就是它的**情绪名**。

---

## 配置

```jsonc
"stickers": {
  "enabled": true,
  "activeSet": "04-线条狗",   // 用哪一套（目录名）
  "position": "after"         // after = 先文字后表情；before = 先表情后文字
}
```

改完**重启桥**生效。启动日志会打印实际用的是哪套：
`[sticker] 装载 1 套表情，当前使用「04-线条狗」（43 个情绪）`

---

## 频率怎么控制

**只在提示词里控制，代码层不做节流。**

人设（`persona.txt`）里写明：

> **情绪明显时才发表情，一次对话最多一张。** 大多数回答不用发。

另外同一次回答里**天然只会发一张**——模型若在一轮里多次索要，后一次会覆盖前一次。

这么设计的原因：加冷却和每小时上限之后，它在该发的时候反而发不出来，
表现就是"明明气氛到了却干巴巴地只回字"，比多发几张更别扭。

想调松紧就改人设那两行；想彻底关掉：`"stickers": { "enabled": false }`。

## 情绪清单（43 个）

不要、写不完了、准备、加油、呸、哼、喂、好棒、好痛、好耶、威胁、完成、寻找、庆祝、
开心、惊、惊讶、惊讶2、打你、打你2、指、探头、摇摆、摊手、晃脚脚、期待、来了、歪头、
沮丧、画圈圈、略、盯、看窗外1、看窗外2、紧张、翘脚脚、谢谢、转圈、送你花花、难过、震惊、
非常好、颓废

模型只能从这里**原样**挑。写错了也没事：库里有容错匹配（多字少字都能对上），
实在对不上会告诉模型可选值，它再重试。

## 它在群里是怎么工作的

- 模型有个 `send_sticker` 工具，工具描述里列着全部情绪名。
- 它自己判断该不该发 —— 人设写着「情绪明显时才发，一次对话最多一张」。
- 真发的时候是**单独一条消息**（不带 @、不带引用），看起来像群友随手甩的图。
- 想立刻试一张：管理员私聊发 `/sticker 加油`；看情绪表发 `/sticker list`。
